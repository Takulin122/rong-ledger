📖 如何綁定 Google 試算表？（3 分鐘設定教學）
  1. 開啟一份新的 Google 試算表 (Google Sheets)。
  2. 點擊上方選單「擴充功能」→「Apps Script」。
  3. 將本專案隨附的 Code.gs 程式碼完整貼上，並確認第 9 行的 API_TOKEN 密碼（例如 RONG-2026-SECRET）。
  4. 點擊右上角「部署」→「新增部署作業」：
    • 選取類型：「網頁應用程式」
    • 執行身分：「我」
    • 誰可以存取：「所有人」（透過自訂 API Token 保護讀寫安全，免除 OAuth 過期問題）
  5. 複製產生的「網頁應用程式網址 (.../exec)」，貼回上方輸入框並填入相同 Token，點擊「儲存設定並測試連線」即完成！
